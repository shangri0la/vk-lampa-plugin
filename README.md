# VK Video — плагин для Lampa

Плагин добавляет в [Lampa](https://lampa.cub.red) раздел «VK Video»: список ваших видео из ВКонтакте, альбомы и просмотр прямо в интерфейсе Lampa.

## Возможности

- Подключение аккаунта прямо в интерфейсе Lampa: экран «VK Видео — подключение аккаунта» с QR-кодом ссылки входа, кнопкой открытия страницы VK и вводом токена с мгновенной проверкой (`users.get`).
- Вход без пароля: на официальной странице VK доступен вход по QR с телефона; пароль вводится только на странице VK, плагин его не видит и не хранит.
- Экран «Мои видео» — все ваши загруженные видео с превью, длительностью и количеством просмотров.
- Просмотр альбомов (`video.getAlbums`, включая системные) и видео внутри альбома.
- Поиск по видео (`video.search`).
- Открытие видео по ссылке (vk.com, vk.ru, vkvideo.ru, video_ext.php) — из раздела и с экрана подключения.
- Сообщества: список ваших групп (`groups.get`, нужен повторный вход с правами сообществ — плагин предложит сам) и их видео.
- Избранное — локальный список на устройстве (долгое нажатие на карточку → «★ В избранное»).
- Сортировка каталога (по дате/названию/длительности — внутри загруженных страниц), кнопка «Обновить».
- Скорость воспроизведения 1x–2x в настройках; «Скачать» для видео, где VK разрешает (`can_download`).
- Кэш разрешённой ссылки на 20 минут — повторный запуск мгновенный.
- Автопроверка обновлений через `version.json` + «VK App ID» в настройках (страховка на случай закрытия встроенного приложения VK).
- Продолжение просмотра: локальная история (не история VK), бейдж «просмотрено N%» на карточках, ряд «Недавно просмотренные», автопродолжение с сохранённой секунды.
- Авто-переход к следующему видео после окончания текущего (отключается в настройках).
- Выбор качества через штатное меню плеера Lampa (все доступные MP4-качества разом) + лимит «Максимальное качество» в настройках (Авто/4K/2K/1080/720/480/360).
- Кэш первой страницы каталога — раздел открывается мгновенно и обновляется в фоне.
- Ошибки с кнопкой «Повторить»; таймаут запросов 20 с; троттлинг под лимит VK API (3 req/s); понятные сообщения (протухший токен, flood, нет доступа).
- Меню карточки по долгому нажатию: смотреть / сначала / скопировать ссылку.
- Если прямых ссылок нет (внешние платформы, права) — iframe-плеер VK (`video_ext.php`).
- Встроенный QR-генератор (qrcode-generator, MIT) — без внешних зависимостей.

## Сборка

```bash
./build.sh   # складывает vendor/qrcode-lib.js + src-plugin.js -> vk-video.js
```

## Установка

1. Разместите `vk-video.js` по HTTPS-адресу (например, GitHub Pages: положите файл в репозиторий, включите Pages).
2. В Lampa: **Настройки → Расширения → Добавить плагин** → вставьте URL файла → Готово.
3. Появится пункт меню **VK Video** и вкладка настроек **Настройки → VK Video**.

## Подключение аккаунта (изнутри Lampa)

1. Откройте пункт меню **VK Video** — при отсутствии токена появится экран подключения с QR-кодом.
2. Отсканируйте QR телефоном (или нажмите «Войти через VK» / «Скопировать ссылку» и откройте её на любом устройстве).
3. На странице VK войдите (доступен вход по QR — без пароля) и нажмите **«Разрешить»**.
4. Скопируйте `access_token` из адресной строки (часть между `access_token=` и `&expires_in`).
5. В плагине нажмите **«Ввести токен»**, вставьте — плагин проверит токен и покажет каталог.

Токен также можно вставить в **Настройки → VK Video → VK Access Token**.

## Получение токена

Токен нужен standalone (implicit flow) со scope `video`:

1. Откройте генератор, например [vkhost.github.io](https://vkhost.github.io) → «Standalone/VK Mobile», либо сформируйте URL вручную:
   ```
   https://oauth.vk.com/authorize?client_id=<APP_ID>&display=page&scope=video,offline&response_type=token&v=5.199
   ```
   (APP_ID — id любого standalone-приложения ВК.)
2. Разрешите доступ — токен появится в адресной строке после `#access_token=...`.
3. Скопируйте его и вставьте в **Настройки → VK Video → VK Access Token**.

⚠️ Токен без scope `offline` действует **24 часа** — с `video,offline` живёт долго (до смены пароля/выхода из сессий). Токен — это доступ к вашему аккаунту: не публикуйте его и не вставляйте в сторонние сервисы.

## Ограничения и риски

- **Implicit flow у VK считается устаревшим** (VK мигрирует на OAuth 2.1 / VK ID) — способ получения токена может перестать работать; в этом случае возможные пути: VK Mini App + VK Bridge или свой backend-прокси.
- Прямые CDN-ссылки VK подписаны и живут несколько часов — плагин всегда запрашивает свежую ссылку перед воспроизведением.
- `files` (прямые ссылки) присутствует не у всех видео (внешние платформы, права) — для таких используется iframe-fallback.
- Внешние видео (YouTube и т.п. через VK) открываются только через iframe `files.external`.

## Структура

- `vk-video.js` — весь плагин (один IIFE-файл).

## Технические детали

| Что | Чем |
|---|---|
| Список видео | `video.get?owner_id=<uid>&extended=1` (пагинация offset) |
| ID владельца | `users.get` по токену, кэш в `Lampa.Storage` |
| Альбомы | `video.getAlbums` |
| Свежая ссылка | `video.get?videos=<oid>_<id>_<hash>&extended=1` перед каждым просмотром |
| Сеть | `Lampa.Network.silent` + очередь 360 мс |
| Ошибки VK | 5 → токен истёк, 6 → flood, 15/600 → нет доступа |
